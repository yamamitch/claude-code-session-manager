# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately with **Report a vulnerability** on the
repository's Security tab (GitHub private vulnerability reporting),
rather than opening a public issue.

Include the steps to reproduce, the PowerShell version (pwsh 7 or Windows PowerShell 5.1),
and the impact you expect. This is a personal project maintained in spare time, so
responses are best effort.

## Supported versions

Only the latest commit on the default branch receives fixes.
